# 課題管理表

HTMLファイル1つで動く、チーム向けの課題管理表です。サーバーもインストールも要りません。

## 特徴

- **一覧・カンバン・ダッシュボード** の3つの画面
- **項目を自由に追加** できる（文字・数値・日付・選択肢・人・チェックボックス）
- **色分けルール**：条件に合う行やセルに色を付ける（例：期限切れで未完了なら赤）
- **Excelからの貼り付け・取り込み**、CSVでの書き出し
- データは **このHTMLファイル自身に保存** される。共有フォルダやOneDriveに置けばチームで使える
- 開いている間は他の人の保存を自動で検知して取り込む。同じ箇所を同時に変えたときだけ、どちらを残すか選べる

## 使い方

1. `index.html` をダウンロードし、好きな名前（例：`課題管理表.html`）で共有フォルダなどに置く
2. **Chrome または Edge** で開く
3. 最初に保存するとき、保存先として **そのHTMLファイル自身** を選ぶ（次回からは「許可」を押すだけ）

Web上のデモページでも操作は試せますが、実際に使うときはダウンロードしたファイルを使ってください。

## 動作環境

- Google Chrome / Microsoft Edge（ファイルへの保存に File System Access API を使います）
